title: "How to reveal and unhide elements in a Revit view"
description: "Show elements that are hidden in a view with Reveal Hidden Elements, then unhide them so they stay visible in that view."

updated: 2026-11-27
---

An element can disappear from a view because it was hidden, not deleted. Reveal Hidden Elements shows hidden items so you can find and unhide them. This changes only the current view.

## 1. Turn on Reveal Hidden Elements

1. In the **View Control Bar** at the bottom of the drawing area, click **Temporary Hide/Isolate**.
2. Click **Reveal Hidden Elements**.

Hidden elements now appear with a magenta outline.

## 2. Unhide the element

1. Click the hidden element to select it.
2. On the contextual **Modify** tab, click **Unhide Element**.

To unhide every element in a category, use **Unhide Category** instead. You can also right-click a hidden element to unhide it.

## 3. Turn the mode off

Click **Temporary Hide/Isolate** again and choose **Reset Temporary Hide/Isolate** or click **Reveal Hidden Elements** to turn it off. Then check the view.

## Things to know

- **Per view:** unhiding in one view doesn't affect other views.
- **Permanent hiding:** elements hidden with **Hide in View** (not Temporary Hide/Isolate) stay hidden until you unhide them. Turn on Reveal Hidden Elements, select the element, and click **Unhide Element**.
- **Filters:** an element can also disappear because a view filter or the Visibility/Graphics settings hide its category. Check those if nothing is hidden with Temporary Hide/Isolate.
