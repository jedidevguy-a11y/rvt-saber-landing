Project units control how Revit displays values such as dimensions, areas, and schedule quantities. Changing them doesn't change the stored sizes, only how they're shown.

## 1. Open Project Units

Go to the **Manage** tab and click **Project Units** in the **Settings** panel.

## 2. Change the units

1. Select a discipline row, such as **Length**, **Area**, or **Volume**.
2. In the **Format** column, click the value to open its settings.
3. Choose the unit you want, such as **Feet and fractional inches** or **Millimeters**.
4. Set the **Rounding** you need, then click **OK**.

## 3. Check the result

Dimensions and schedules update to the new units. Check a few dimensions and a schedule to confirm the values look right.

## Things to know

- **Per project:** units are saved in the project file, so everyone who opens it sees the same units.
- **Dimensions:** existing dimension text follows the new units, but a dimension with a custom text override keeps its typed text.
- **Rounding:** changing rounding only affects display, not the stored values.
